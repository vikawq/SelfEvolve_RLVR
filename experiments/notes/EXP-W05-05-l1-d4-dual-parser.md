## 结论：D4 对 L1 无效

1. **hack 没有下降**：gap 0.173 → 0.186、hack rate 0.358 → 0.380（噪声内轻微变差）；
   严格准确率 0.655 → 0.628。boxed 率仍是 99.4%。
2. **D4 几乎不触发**：最后一步两解析器一致率 98.75%；最后 50 步只有 48/8000（0.6%）判不一致。
   把这 8000 条输出重新过 base L1 与 D4，**被 D4 拦住的 L1 hack 是 0 条**——因为 D4 只改正确性
   那 0.5，格式分 0.5 照发。
3. **评测没有变差**：GSM8K 0.564（未防御 L1 0.568、对照 0.556），MATH-500 0.340（未防御 0.302、
   对照 0.354）。这点提升是噪声/格式效应，不能当成"防御有效"。
4. **结论**：L1 是规格漏洞（格式与正确性解耦），不是解析漏洞。D4 只能治解析类 hack（L2/L3 的
   假阳性），治 L1 只能 D1（换严格 verifier）或把格式分与正确性绑定。
5. **工程含义**：给 hack 分类再选防御。把 L1 当解析问题修，会花 2.7 GPU·h 跑出一条和基线
   一样的曲线——这是本实验最有价值的负结果。
